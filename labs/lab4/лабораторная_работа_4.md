
# Решение задач

## Задача 1: Номер четверти плоскости для точки M(x, y)

### Алгоритм
1. Считываем координаты точки `x`, `y` (тип `double`; по условию `x ≠ 0`, `y ≠ 0`, точка не лежит на осях).
2. Определяем знаки координат:
   - `x > 0`, `y > 0` → `N = 1`;
   - `x < 0`, `y > 0` → `N = 2`;
   - `x < 0`, `y < 0` → `N = 3`;
   - `x > 0`, `y < 0` → `N = 4`.
3. Выводим номер четверти `N`.

### Входные данные
```
-3 5
```

### Вывод
```
2
```

*(проверка: x = −3 < 0, y = 5 > 0 — точка во второй четверти)*

## Задача 2: Замена числа полусуммой двух других

### Алгоритм
1. Считываем три попарно различных числа `x`, `y`, `z` (тип `double`).
2. Вычисляем сумму `s = x + y + z`.
3. Если `s < 1`:
   - находим наименьшее из трёх чисел и заменяем его полусуммой двух остальных:
     - если минимальное `x` → `x = (y + z) / 2`;
     - если минимальное `y` → `y = (x + z) / 2`;
     - иначе минимальное `z` → `z = (x + y) / 2`.
4. Иначе (`s ≥ 1`):
   - сравниваем `x` и `y`;
   - если `x < y` → `x = (y + z) / 2`;
   - иначе → `y = (x + z) / 2`.
5. Выводим новые значения `x`, `y`, `z`.

### Входные данные
```
3 -1 0.5
```

### Вывод
```
3 1.75 0.5
```
*(проверка: s = 3 − 1 + 0.5 = 2.5 ≥ 1, значит заменяем меньшее из x и y, то есть y = −1; новое y = (3 + 0.5) / 2 = 1.75)*
