# Решение задач

## Задача 1: Сумма цифр числа

### Алгоритм
1. Считываем целое число `n` (тип `long long`).
2. Берём модуль числа: `n = abs(n)`, чтобы отрицательные числа обрабатывались так же, как положительные.
3. Задаём переменную `sum = 0` для накопления суммы цифр.
4. Пока `n > 0`, выполняем цикл `while`:
   - последняя цифра числа `n % 10` прибавляется к `sum`;
   - число уменьшается на один разряд: `n /= 10`.
5. Выводим результат: `Sum of digits: <sum>`.

### Входные данные
```
12345
```

### Вывод
```
Sum of digits: 15
```

*(проверка: 1 + 2 + 3 + 4 + 5 = 15)*

## Задача 2: Сумма первых n чётных чисел

### Алгоритм
1. Считываем целое число `n` — количество чётных чисел, которые нужно сложить.
2. Задаём переменную `total = 0` для накопления суммы.
3. В цикле `for` перебираем `i` от `1` до `n` включительно:
   - `i`-е чётное число равно `2 * i`;
   - прибавляем его к `total`: `total += 2 * i`.
4. Выводим результат: `Sum of <n> even numbers = <total>`.

### Входные данные
```
5
```

### Вывод
```
Sum of 5 even numbers = 30
```

*(проверка: 2 + 4 + 6 + 8 + 10 = 30; по формуле n · (n + 1) = 5 · 6 = 30)*
