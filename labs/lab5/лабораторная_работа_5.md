# Решение задач

## Задача 1: Решение квадратного уравнения

### Алгоритм
1. Считываем коэффициенты `a`, `b`, `c` (тип `double`).
2. Выводим исходное уравнение: печатаем члены `ax²`, `bx`, `c` со знаками (через `to_string` и `abs`, коэффициенты `±1` не печатаем), затем ` = 0`.
3. Проверяем корректность данных:
   - `a = 0`, `b = 0`, `c ≠ 0` → вывод `Error: incorrect equation!`, конец программы;
   - `a = 0`, `b = 0`, `c = 0` → вывод `This equation has an infinite number of roots.`, конец программы;
   - `a = 0`, `b ≠ 0` → линейное уравнение, один корень `x = −c / b`.
4. Для квадратного уравнения вычисляем дискриминант `D = b² − 4ac`:
   - `D < 0` → `D<0, this equation has no real roots.`;
   - `D = 0` → два равных корня `x = −b / (2a)`;
   - `D > 0` → два корня `x₁,₂ = (−b ± √D) / (2a)`.
5. Ветвление реализуется через `if / else if / else`.

### Входные данные
```
1 -2 1
```

### Вывод
```
Equation: x^2 - 2x + 1 = 0
This equation has two equal real roots:  x_1,2 = 1
```

*(проверка: D = (−2)² − 4·1·1 = 0, x = 2 / 2 = 1)*

## Задача 2: Название дня недели по номеру

### Алгоритм
1. Считываем номер дня недели `day` (целое число).
2. Через `switch (day)` выбираем:
   - `1` → `Monday`;
   - `2` → `Tuesday`;
   - `3` → `Wednesday`;
   - `4` → `Thursday`;
   - `5` → `Friday`;
   - `6` → `Saturday`;
   - `7` → `Sunday`;
   - любое другое значение → `default`: сообщение об ошибке.
3. Выводим название дня или сообщение об ошибке.

### Входные данные
```
3
```

### Вывод
```
Wednesday
```

*(проверка: номер 3 соответствует среде)*
