
# Решение задач

## Задача 1: Перестановка цифр трёхзначного числа (abc → bac)

### Алгоритм
1. Считываем трёхзначное число `abc`.
2. Разбиваем его на цифры с помощью целочисленного деления (`/`) и остатка (`%`):
   - `a = abc / 100` — сотни;
   - `b = (abc / 10) % 10` — десятки;
   - `c = abc % 10` — единицы.
3. Собираем новое число в порядке `bac`: `bac = b * 100 + a * 10 + c`.
4. Выводим результат.

### Входные данные
```
123
```

### Вывод
```
213
```

## Задача 2: Вычисление выражения x − y²/3! + z²/5!

### Алгоритм
1. Считываем `x`, `y`, `z` (тип `double`, чтобы деление было вещественным).
2. Подставляем значения факториалов: `3! = 6`, `5! = 120`.
3. Вычисляем: `result = x − (y·y)/6 + (z·z)/120`.
4. Выводим результат.

### Входные данные
```
2.14 3 5
```

### Вывод
```
0.848333
```

*(проверка: 2.14 − 9/6 + 25/120 = 2.14 − 1.5 + 0.208333 = 0.848333)*
